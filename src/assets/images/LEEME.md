# Carpeta de Imágenes

Aquí puedes guardar todas las fotografías, logotipos e íconos de tu proyecto. 

Al usar React (Vite), la mejor forma de agregar una imagen en tus componentes es importándola directamente en la parte superior del archivo. Por ejemplo:

```javascript
import logoSkilled from '../assets/images/logo.png';

// Y luego en tu componente:
<img src={logoSkilled} alt="Logo Skilled" />
```
